# Modern Business Bootstrap Clone

This project is a recreation of the Modern Business website template from Start Bootstrap using only HTML and CSS as part of my Software Engineering training journey.

## Project Overview

The goal of this project was to strengthen my understanding of:

- HTML structure
- CSS styling
- Layout design
- Responsive thinking
- Project organization
- Git and GitHub workflow

The original template was provided as a reference during training:
https://startbootstrap.com/previews/modern-business

## What I Learned

Working on this project helped me improve my understanding of:

- Structuring multi-section web pages
- Working with containers, spacing, and alignment
- Styling navigation bars, cards, buttons, and sections
- Organizing CSS properly
- Understanding how professional website layouts are built
- Using Git and GitHub to track project progress

This project also showed me the importance of repetition and rebuilding projects to improve speed, confidence, and deeper understanding.

## Challenges Faced

Some of the challenges I encountered included:

- CSS positioning and layout alignment
- Managing spacing and responsiveness
- Structuring sections correctly
- Understanding how different components connect together

Despite the challenges, completing this project gave me more confidence in my ability to learn and build.

## Growth Reflection

This project took me over a week to complete because I focused on understanding the concepts instead of rushing through them.

One of my next goals is to rebuild this same project within a shorter time frame to improve:
- speed
- accuracy
- confidence
- and mastery of the fundamentals

I now understand that every project is an opportunity to become more structured and intentional as a developer.
